## 📱 OPTIMIZACIONES MOBILE-FIRST

### 1. CTA STICKY (Fijo en la parte inferior)
- Siempre visible mientras el usuario hace scroll
- Botón grande: "COMPRAR ENTRADA"
- Color naranja, alto contraste
- Tamaño mínimo: 56px de altura

### 2. VELOCIDAD DE CARGA
- Imágenes optimizadas (WebP)
- Lazy loading
- Scripts defer/async
- CSS crítico inline

### 3. TOUCH TARGETS
- Botones mínimo 44x44px
- Espaciado adecuado entre elementos
- Sin elementos muy pequeños

### 4. NAVEGACIÓN
- Menú hamburguesa simple
- Scroll suave
- Anclas claras

---

## 🎨 RECOMENDACIONES UX/UI

### COLORES Y CONTRASTES
- **CTA Primario:** Naranja (#FF7A1A) - Alta visibilidad
- **CTA Secundario:** Azul (#0A4D9E) - Confianza
- **Urgencia:** Rojo (#EF4444) - Atención
- **Texto:** Alto contraste (WCAG AA mínimo)

### TIPOGRAFÍA
- Títulos: Bold, 24-32px (mobile)
- Cuerpo: Regular, 16-18px
- CTAs: Bold, 18-20px

### ESPACIADO
- Secciones: Padding vertical 3-4rem
- Elementos: Márgenes consistentes
- Respiración visual adecuada

### ANIMACIONES
- Sutil, no distractora
- Enfoque en CTAs (pulse suave)
- Transiciones suaves (0.3s)
