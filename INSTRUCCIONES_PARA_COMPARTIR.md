# 📤 CÓMO COMPARTIR LA PÁGINA WEB CON LOS EXPOSITORES

## 🎯 OPCIÓN 1: Compartir en Línea (RECOMENDADO)

### **Opción A: GitHub Pages (GRATIS)**

1. **Crear cuenta en GitHub** (si no tienes): https://github.com
2. **Crear un nuevo repositorio**:
   - Nombre: `congreso-cheqfirma`
   - Marcar como "Public"
3. **Subir los archivos**:
   - index.html
   - styles.css
   - script.js
   - README.md
4. **Activar GitHub Pages**:
   - Ve a Settings > Pages
   - Source: Deploy from a branch
   - Branch: main
   - Carpeta: / (root)
   - Guardar
5. **Compartir el link**:
   - Link será: `https://tu-usuario.github.io/congreso-cheqfirma/`

**Ventajas:**
✅ Gratis
✅ URL profesional
✅ Actualizaciones instantáneas
✅ Accesible desde cualquier dispositivo

---

### **Opción B: Netlify (GRATIS - MÁS FÁCIL)**

1. **Ir a** https://www.netlify.com/
2. **Crear cuenta** (puede ser con Google)
3. **Arrastrar la carpeta del proyecto** a Netlify
4. **Listo!** Te da un link automáticamente
5. **Personalizar dominio** (opcional):
   - Puedes cambiar de `random-name.netlify.app` a `cheqfirma.netlify.app`

**Link de ejemplo:** https://cheqfirma.netlify.app

**Ventajas:**
✅ SUPER FÁCIL (arrastrar y soltar)
✅ Gratis
✅ URL personalizable
✅ Actualizaciones fáciles

---

### **Opción C: Vercel (GRATIS)**

Similar a Netlify:
1. https://vercel.com/
2. Crear cuenta
3. Importar proyecto
4. Link generado automáticamente

---

### **Opción D: Firebase Hosting (GRATIS)**

1. https://firebase.google.com/
2. Crear proyecto
3. Instalar Firebase CLI
4. Deploy

## 🎯 OPCIÓN 2: Compartir Localmente

### **Para que los expositores vean en sus computadoras:**

1. **Comprimir la carpeta**:
   - Click derecho en la carpeta "Congreso Foro Cheq Firma"
   - Enviar a > Carpeta comprimida
   - Se creará un archivo .zip

2. **Compartir el .zip por**:
   - ✉️ Email
   - 💬 WhatsApp (si es pequeño)
   - ☁️ Google Drive
   - ☁️ Dropbox
   - ☁️ OneDrive

3. **Instrucciones para los expositores**:
   ```
   1. Descomprimir el archivo .zip
   2. Hacer doble click en "ABRIR_PAGINA_WEB.bat"
   3. O abrir "index.html" con su navegador
   ```
