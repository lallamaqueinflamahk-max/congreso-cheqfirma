## 🆘 SOLUCIÓN DE PROBLEMAS:

### **Si una foto no aparece:**
1. Verifica el nombre (debe ser exacto)
2. Verifica que esté en `images/expositores/`
3. Refresca con Ctrl + F5
4. Verifica la extensión (.jpg o .png)

### **Si necesitas cambiar una foto:**
1. Elimina la anterior de `images/expositores/`
2. Guarda la nueva con el mismo nombre
3. Refresca el navegador

### **Si necesitas agregar más expositores:**
1. Edita `index.html`
2. Copia el bloque de código de un expositor existente
3. Cambia nombre, horario, tema
4. Guarda la foto con el formato `nombre-apellido.jpg`
