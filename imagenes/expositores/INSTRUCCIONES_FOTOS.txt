✅ REQUISITOS DE LAS FOTOS:

• Formato: JPG o PNG
• Tamaño recomendado: 400x400 px (cuadrada)
• Peso: Máximo 500KB por foto
• Fondo: Preferiblemente neutro o profesional
• Tipo: Foto tipo carnet/profesional
• Calidad: Alta resolución, bien iluminada


🔄 PASOS PARA AGREGAR LAS FOTOS:

1. Conseguir las fotos de cada expositor
2. Recortar/editar para que sean cuadradas (1:1)
3. Renombrar con el nombre exacto de la lista
4. Guardar en esta carpeta (imagenes/expositores/)
5. Actualizar la página web


💡 HERRAMIENTAS ÚTILES:

• Para recortar: Paint, Photoshop, GIMP (gratis)
• Para comprimir: TinyPNG.com (online, gratis)
• Para crear avatar si no hay foto: UI Avatars (online)

⚠️ IMPORTANTE:

• Los nombres de archivo NO deben tener espacios
• Usar minúsculas y guiones (como se indica)
• La extensión debe ser .jpg o .png
• Si la foto no existe, se mostrará el avatar con iniciales


🔍 VERIFICAR:
